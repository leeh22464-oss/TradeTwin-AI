# TradeTwin AI 三分钟演示与恢复

所有产品、报告、费率及周期均为合成示意。运行版本以“知识与规则”中的推演知识源为准，模型模式以页面标记为准；无密钥时依然能运行确定性闭环。

## 演示准备

按 [README](../README.md) 启动。先确认运行知识可用，型号为 NL-L24，报告为 TR-DEMO-NL-L24-01。旧 NL-L 仅通过明确别名兼容，不扩展为任意 NL-L 型号。知识文件更新后旧推演/报价会失效，案件配置和会话保留；先核对并保存配置再重新推演，不删除数据制造干净状态。

## 演示顺序

| 时间 | 操作与讲解 |
|---|---|
| 0:00–0:30 | 从案件队列新建合成询盘：`36 Watt statt 24 Watt, IP44, DRV-A`。展示无模型时也识别为 36W，而不是把被替代的 24W 当作要求。 |
| 0:30–1:00 | 推演并打开证据：TR-DEMO-NL-L24-01 第 2 页，核对真实知识文件中的范围和 RULE 引用，查看版本及来源指纹。 |
| 1:00–1:30 | 显示已知补测费用小计 €2,100、规划估算 8 天；说明 EMC 仍是人工复核，不能把预设报告确认当成本次变更批准。电气范围按原包 18–30W 保守判断，不使用旧演示的 18–40W。 |
| 1:30–2:00 | 生成英语/德语待确认草稿和中文岗位待办。指出已知费用小计与最终待定价格不同，交期未承诺。 |
| 2:00–2:30 | 选有证据支持的方案 A，变为 30W/IP44；温升补测移除，防护补测保留，已知小计 €900、规划 7 天，EMC 仍待复核。也可输入 `Option A is too expensive, we take option B` 验证肯定选择 B。 |
| 2:30–3:00 | 对 36W/IP44 更换 DRV-B，展示打样 3 天先于测试、再更新文件：`3+max(6,5,7,3)+2=12`，已知费用 €3,600。打开审计与导出说明费用、来源、模型模式和人工边界。 |

## 可选反例

- 仅改 28W：不应自动升为 30W/IP44 或推荐 36W，不添加无关防护补测。
- 要求 45W/IP65：降功率方案仍保留 IP65，不能擅自降低防护等级。
- `material to be confirmed later` 不应成为材料名称；`German instructions` 不应改变目标市场。
- `24W or 36W` 无法确定目标时要求确认，不能按旧 24W 继续生成确定报价。
- 来源文件缺失或冲突时运行知识不可用；不以旧 seed 已确认资料代替当前知识。历史引用可只读查看，不参与本轮推演。

## 恢复与验收

服务停止时在项目目录重新启动；配置 `.env` 后需重启后台。保留 SQLite、案件和上传原件。扫描 PDF 无 OCR，失败文件需补录；合成预设确认不代表真实机构验证。模型不可用时检查演示/回退标记，不能把模板说成真实模型调用。

`npm run test:smoke` 会创建合成验收案件，应对隔离服务运行（用 `TRADETWIN_API_URL` 指向隔离端口）。实际验证以 [验证记录](验证记录.md) 为准。
