# TradeTwin AI 三分钟演示与恢复

## 演示准备

按 [README](../README.md) 启动并打开工作台。应用默认从“案件队列”开始，先确认左侧显示“演示数据环境”和当前模型模式（无密钥时为本地演示）。

预置案件可能已经被之前的演示或隔离验收改成 **30W / IP44**。不要删除案件或重置运行数据库：演示前进入详情，把“客户要求 / 待核验配置”恢复为 **36W / IP44**，保存后重新推演；也可以在队列中新建一个明确标记为合成的演示案件。这样才能稳定复现下面的金额和排期。

## 演示顺序

| 时间 | 操作与讲解 |
|---|---|
| 0:00–0:25 | 从案件队列开始：说明这里是多案件入口。输入客户、案件、型号或买家原话关键词，演示 AND 搜索；再点选“含补测”或“含人工核验”，说明条件可以叠加。 |
| 0:25–0:45 | 切换更新时间/客户/费用排序，指出未知费用始终显示“待核验”并排在已知费用之后；可短暂展示每页 10/20、列显示和舒适/紧凑。 |
| 0:45–1:05 | 进入 36W/IP44 案件，说明单案保留现有专注工作区：配置、证据、账单、报价方案四个分段锚点；固定导航和账单摘要让当前结论保持可见。 |
| 1:05–1:30 | 点击“重新推演”，打开 TR-001/TR-002/TR-003 证据页，说明各测试项目独立范围与页码原文；EMC 沿用不能只看驱动相同。 |
| 1:30–1:50 | 显示温升与防护两项补测，€2,100 示意费用，解释测试并行、文件更新串行的 `max(6,5)+2=8` 个工作日；指出费用和排期均需检测机构确认。 |
| 1:50–2:10 | 点击“英德回复”，再点击“生成 商务邮件”（或“生成 RFQ”）；点击“内部待办”查看业务、品质、采购中文任务，并强调输出会标记演示/回退模式。 |
| 2:10–2:35 | 在对话中发送“客户选择方案 A：30W / IP44，请重新计算；不要承诺具体交期”。核对第二轮实际重算为保留防护补测 €900 / 7 天，温升补测移除。 |
| 2:35–2:50 | 再发送“暂不承诺具体交期，等实验室排期确认”，展示回复、交期口径和待办同步变化。 |
| 2:50–3:00 | 点击“返回案件队列”，确认案件状态、费用/交期和已有回复同步；打开证据抽屉或“审计记录”，说明页码原文、规则版本、模型模式和人工覆盖留痕。 |

## 可选的队列与窄屏展示

- 在 1440px 或 1060px 展示桌面队列表格；在 900px、768px、399px 或 390px 展示 ≤1024px 的摘要列表，避免把比较表压缩成不可读的窄列。
- 在 ≤860px 宽度打开 Menu，展示侧栏独立滚动、X 关闭、`Escape` 关闭、焦点循环以及主内容 `inert`；不要把这段操作讲成完整 WCAG 认证。
- 单案编辑任一配置、数量或单价后点击“返回案件队列”或切换其他案件，会打开未保存确认弹层；点击刷新或“新建询盘”会提示先保存。发送消息、点击“选择方案 A 并重算”/“在对话中讨论方案 B”、或生成报价会先自动保存。保存失败时错误可见，输入保留，后续动作不继续；可用 Escape 关闭弹层并继续编辑。

## 恢复步骤

- 服务异常：重启 `npm run dev`，刷新页面；SQLite 中的案件、消息、报告和审计事件会保留。
- 模型不可用：查看顶部的本地演示/回退标记，继续验证规则引擎和模板回复；不要把模板输出讲成真实模型调用。
- 演示案件状态不符合预期：按“演示准备”进入详情恢复 36W/IP44 并保存、推演，或新建合成案件；不要删除用户上传或案件来制造干净状态。
- 文件导入失败：查看失败原因，改用可提取文字的 PDF、Markdown 或人工确认的结构化范围；扫描 PDF 本版没有 OCR，也不会把空文字当作证据。
- 队列筛选后没有结果：点击“清除筛选”；返回队列时条件会保留，必要时再清除。
- 展位无需外部网络即可展示规则主链路；真实模型调用依赖用户配置的 OpenAI 兼容服务。
