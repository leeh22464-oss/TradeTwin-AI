# TradeTwin AI 构建要求

更新：2026-10-31。根据本项目已确认的框架、创新点、AI+出海赛题及当前开发授权整理。本文件与根目录 AGENTS.md 由本轮开发补建，历史资料保留原样。

## 目标

开发可运行、可重复验证的贸链通 TradeTwin AI。业务员答应客户之前，先知道这次改动的合规账单。完成从询盘理解、证据核验、确定性推演，到本地化报价与反馈修正的端到端流程；不能只做静态页面或预设结果演示。

## 必须完成的体验

1. 工作台：案件/询盘列表，当前和客户要求的产品配置，可编辑功率、IP、驱动、材料、市场、数量与报价场景；支持新建案件、保存和重新打开。
2. 覆盖推理：对报告的测试项目与适用范围逐项判断，分开显示需补测、可沿用、需更新、待人工核验，展示命中规则与证据页原文。
3. 最小补测：合并去重测试项目，计算费用和周期，提供 A/B 方案。周期必须解释并行/串行关系，不能直接把若干单项天数任意拼成总交期。
4. 两个相关工作流：外贸业务的变更理解/报价，以及品质的证据核验/补测，共享一个产品配置、证据库和会话。
5. 本地化产出：英语、德语报价回复及中文业务/品质/采购待办；支持商务邮件与 RFQ 两个场景，体现格式和语气差异。
6. 至少两轮对话：支持客户选 A、改变功率/驱动/防护等级和暂不承诺交期；重新计算补测、报价、交期与岗位待办，不只改回复文字。
7. 至少两类校验：产品证据/目标国合规相关校验；合同或商务承诺校验（如补测未确认却承诺原交期、无条件认证承诺）。至少两种反馈：文本批注、风险标记/配置对比。
8. 证据库：预置明确标为合成的报告、规格书、DoC、标签和说明书；可打开原文/页码，支持真实文件导入与范围人工确认。缺少文字的扫描 PDF 提示人工补录，不伪造成功。
9. 知识库：可检索本地知识文档、规则来源与适用范围，支持添加/导入 Markdown；可选配置 Obsidian vault 只读导入，默认不扫描用户电脑。
10. 审计：保存配置与会话轮次、推理指纹、规则版本、模型来源、生成/修改/人工覆盖事件。重复相同请求返回同一推理结果，避免重复创建审计事件。
11. 导出：可导出案件报告/报价与证据清单，方便检查演示和交付。
12. 模型：完整实现服务端 OpenAI 兼容模型适配器、超时/错误处理、严格结构校验及可见回退。无凭据时演示模式仍可运行，真实调用状态必须据实呈现。

## 数据与规则

- 产品基线：NL-L 系列，24W、IP20、DRV-A、原材料组合、德国市场。
- 安规示例 TR-001 覆盖 18–30W、IP20、DRV-A；EMC TR-002 具有独立明确的驱动、功率及结构适用范围；RoHS TR-003 约束材料组合。不能以报告级功率范围笼统推导所有测试。
- 三张核心表：报告覆盖范围；参数—测试项目映射（约 15 条、带编号版本）；费用周期。
- 36W/IP44：温升及防护补测；满足独立覆盖条件的 EMC/RoHS 可沿用；更新 DoC/标签/说明书。
- 30W/IP44：沿用功率范围内的温升结果，仍需防护补测。缺乏充足证据时给人工核验。
- 示意费率：温升 €1,200 / 6 个工作日；防护 €900 / 5 天；EMC €1,500 / 7 天；文件更新内部费用 / 2 天。明确采用补测并行后串行文件更新的演示排期：36W/IP44 为 max(6,5)+2=8 天，30W/IP44 为 5+2=7 天。其他示例的 +10 天不是已验证结论。
- 不随模型回答改变费用、测试结果和证据。标注合成数据、规则适用范围与专业确认责任。
- 费用最小化是在当前已确认规则与证据下合并必要测试，不宣称完整法规自动认证。

## 自主技术决策

采用 React/TypeScript/Vite、Express、Node 24 内置 SQLite、本地知识库、OpenAI 兼容模型协议。无需绑定 Obsidian、特定云平台或付费服务。可在实现发现限制时作常规调整并更新说明。

## 验收

- 干净安装后可按 README 启动；具备演示数据重现路径、空状态、加载状态和可恢复错误。
- 单元测试覆盖规则边界、费用/周期、未知与缺失、变更依赖、方案 A 第二轮及合同表述。
- API 集成测试覆盖持久化、文件处理、审计、幂等、模型未配置/失败回退和导出；浏览器实测主流程及窄屏。
- 有效运行一次“36W/IP44 → 证据与补测账单 → 英德报价 → 选 A → 30W/IP44 + 防护补测 → 不承诺具体交期”的完整操作。
- README、.env.example、配置导出/模型说明、第三方组件清单、1 页方案与 3 分钟演示说明齐全。
- 不因黑客松时限压缩完整性，不为了凑指标伪造 98% 召回率。未有真实凭据时清楚列出未完成的真实模型验收。
