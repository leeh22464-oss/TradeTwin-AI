# TradeTwin 工作台界面契约

本轮用户授权自主开发，采用 code-led Operate 模式，直接实现与测试，不增加视觉方案确认环节。产品事实见 PRODUCT.md，技术验收见 BUILD_PROMPT.md。

## Direction contract

THESIS: 外贸业务正在处理一笔真实配置变更，界面首先呈现配置差异、证据与代价；不使用营销落地页或装饰性仪表盘。

OWN-WORLD: 从贸易单据的清晰排版提取冷白/墨绿/浅青灰、对齐的数据列和紧凑标签；使用现代无衬线系统字体。墨绿侧栏、白色工作表、低饱和语义状态、清楚的1px分隔与一致的8px控件圆角。只将配色、密度与变更对照这一签名交互带入标准产品UI，不仿造纸张纹理或印章。

STORY: 选择询盘，调整配置，看清补测账单与逐页证据，生成本地化回复，再通过对话选择替代配置。模型模式与合成数据始终可见。

FIRST VIEWPORT: 约210px深墨绿侧导航及底部模型状态；主区顶部案件名称/保存状态/新建操作；下方配置编辑和宽幅账单，右侧窄栏用于买家原话及第二轮对话。账单中参数变化带将24W/IP20与36W/IP44并列，下面列表显示测试状态、理由、证据、费用。主操作为“重新推演”。首屏读到任务而不是欢迎大标题。1400px下工作区与对话区并列，窄屏按任务顺序堆叠。

FORM: trade paperwork clarity（grounded candidate 5）；seed:b0d8f1bd95e14ea9。其他候选家族为产品规格表、标准文献、工业包装、实验档案、交通导向及贸易目录。取信息对齐和状态一致性，不移植外部世界的导航或装饰。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 功能面

- 变更工作台：案件切换/新建、配置编辑、基线对比、账单/证据、方案A/B、英德回复/内部待办、两轮对话、下载报告。
- 证据库：报告筛选、全文页码与范围、实际文件导入、人工确认抽取，失败可恢复。
- 知识与规则：可搜索并添加本地知识、查看规则及费用周期、显式Obsidian导入。
- 审计与接入：案件事件与人工覆盖理由；真实模型配置状态、连接测试、错误说明。

不为演示创建假可点击控件；已实现操作接真实API。空状态说明下一步，错误提供重试，加载期间禁用提交。表单具可见label、键盘焦点、语义按钮与状态文本。动效150ms，仅用于参数更新/状态变化；尊重reduced-motion。
