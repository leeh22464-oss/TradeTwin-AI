# 跨部门问题卡

问题卡把“证据、覆盖状态、测试项目、费用/周期假设、责任、待确认事项和关闭依据”放在同一条记录里。它不是群聊，也不是多个 AI Agent 的包装；每条卡片都应能被品质/合规、工程、采购/实验室和业务岗位接力处理。

## 推荐交接

1. 品质/合规根据页码证据创建问题，选择风险级别、覆盖状态和下一步。
2. 工程确认实际型号、配置、驱动或样品覆盖关系，写入 `human_decision`。
3. 采购/实验室确认补测项目、费用、周期和假设来源，更新 `human_confirmed`。
4. 业务根据确认结果生成买家追问或内部报价待办；未确认时不能向外承诺“已符合”或发送确定报价。
4. 关闭时记录决定人角色、依据和更新后的文件/数据版本；源证据不能被覆盖。

`issue-card-schema.json` 是字段契约，`sample-issues.jsonl` 是可重复的合成协作示例。
