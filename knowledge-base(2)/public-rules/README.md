# 公开规则与检查表

本目录只保存官方公开来源索引、带范围限制的规则卡和演示检查表。它不复制标准全文，也不构成法律意见。

## 来源维护

使用 `source-index.json` 中的 `source_id` 作为来源主键；规则卡通过 `source_id` 回链。每次更新要记录官方版本/日期和 `retrieved_on`，并重新确认产品对象、成员国市场、经济运营商角色及其他适用前提。

## 规则卡类型

- `cross_document_consistency`：对产品主数据和文件事实做确定性比对。
- `source_derived_boundary`：记录官方来源主题，但需要专业人员确认适用性和证据充分性。
- `applicability_review`：先确认完整灯具、光源或控制装置等对象，再决定是否适用。
- `document_quality` / `delivery_quality`：帮助减少返工和交付缺项，不自动等于法定硬伤。

## 使用限制

不要把“发现资料冲突”直接改写成“产品违法”。不要把可替换光源的能效要求自动套到整灯。不要把标准编号当作标准正文。正式生产使用前必须由企业指定的品质/合规人员维护规则版本和判定边界。
