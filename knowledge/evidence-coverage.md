# Evidence coverage model (synthetic demo data)

TradeTwin AI compares a requested configuration against each report's project-level coverage conditions. The demo records report IDs, page references, model series, parameter ranges, test conditions and verification state. It does not replace a testing laboratory or certification body's decision.

- TR-001: NL-L, 18–30W, IP20, DRV-A, original-material, EU/DE; temperature, electrical-strength and IP evidence.
- TR-002: NL-L, 18–40W, DRV-A, original-material, EU/DE; EMC evidence. IP is not an independent condition for this report.
- TR-003: NL-L, original-material, EU/DE; RoHS evidence.

Unknown, missing or unverified evidence is routed to manual review.
