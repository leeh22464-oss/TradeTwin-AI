# 合成测试集

`hard-issue-test-set.jsonl` 有 50 条范围内标注实例，其中 40 条为 `is_hard_issue: true`，10 条用于验证正常项、建议和人工复核不会被过度分类。每条实例都带规则 ID、资料包 ID、文件、正整数页码和金标准引用。

## 指标

硬伤召回率：`TP / (TP + FN)`。运行应用后填写 `expected-results.json` 中的实际计数；98% 是企业验收目标，不是本合成包已经取得的生产成绩。页码定位应单独统计，不得以找到文件代替证据页码正确。

## 覆盖类型

型号、额定功率、电压、版本/日期、测试样品、声明身份、文件缺失、字段缺失、不可读文件、语言/适用性边界和询盘变更。

测试集的作用是验证知识库接入、规则匹配、证据回传和风险分级。正式使用前应补充经授权、代表性和独立标注的真实资料。
