# 合成业务资料

本目录中的所有资料均是 `synthetic_demo`，由 `canonical-product.json` 派生，用于演示参数变更、覆盖范围判断、最小补测、合规账单、报价选项、页码定位、跨文件一致性和跨部门协作。它们不代表真实企业、客户、检测机构或证书。

## 资料包

| pack_id | 目的 | 预埋内容 |
|---|---|---|
| `PACK-BASELINE-001` | 基准闭环 | 24W/IP20/DRV-A 命中报告 18–30W/IP20/DRV-A 覆盖 |
| `PACK-CONFLICT-001` | 参数变更与报价 | 24W/IP20 → 36W/IP44；旧报告、DoC、标签和报告版本保持冲突；含覆盖、映射和费用文件 |
| `PACK-MISSING-001` | 异常与人工复核 | 覆盖范围不可读、IP/驱动缺失、无法生成确定报价 |

## 页码规则

每个文件使用 `第 N 页` 作为页边界。测试集中的 `quote` 必须能在对应文件的同一页找到。文件名中的编号对应 `document_id` 的最后一段，但应用应以文件头部字段为准。费用和周期文件必须标明 `synthetic`、估算版本和 `human_confirmed` 状态。
